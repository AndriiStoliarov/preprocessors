# 🎨 preprocessors

## less

**Less** (**Leaner Style Sheets**; sometimes stylized as **LESS**) is a dynamic preprocessor style sheet language that can be compiled into Cascading Style Sheets (CSS) and run on the client side or server side. Designed by Alexis Sellier, Less is an open source project.

## sass

**Sass** (short for **syntactically awesome style sheets**) is a preprocessor scripting language that is interpreted or compiled into Cascading Style Sheets (CSS). SassScript is the scripting language itself.
